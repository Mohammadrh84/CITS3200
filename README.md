# CITS3200
CITS3200: Mental Load Report Generation Project

**Project Brief**
The mental load has become a widely discussed topic, with growing recognition of the invisible cognitive work performed to achieve goals that benefit others. Despite this interest, people have very few opportunities to understand or measure their own mental load in a meaningful way, Researchers at The University of Western Australia have developed a validated mental load questionnaire, creating an opportunity to transform survey responses into engaging, personalised feedback that helps participants better understand their own experiences. A previous CITS3200 project developed a mobile application to deliver this experience. While the app demonstrated the concept successfully, it proved too slow and cumbersome for participants to use, limiting its suitability for research. This project aims to rethink the user experience by developing a simpler, faster, and more intuitive web-based platform that allows participants to complete the questionnaire and instantly receive an automated report The system should score responses, generate clear visualisations and plain-language explanations, and produce an attractive report that participants can view online or download, The end product should be easy for participants to use, straightforward for researchers to deploy, and suitable for use in future research studies.
